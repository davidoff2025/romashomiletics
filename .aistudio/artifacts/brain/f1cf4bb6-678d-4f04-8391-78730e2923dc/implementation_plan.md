# 2026–2027 罗马书 BSF 讲道法式研经分析工作台 (BSF Homiletics)

一款专为 2026–2027 中文 BSF DOLM #7461《罗马书》（从罪孽到恩典）设计的结构化经文分析与同工备课工作台。集成 BSF 讲道法式研经（Homiletics）四步教练引导、中英文独立切换模式、圣经人名地名智能合词计数字数校验、30周全学年教学大纲进度追踪、本地实时暂存及一键标准格式导出打印。

## 1. Overview & Core Concept

- **What It Does**: 提供基于 2026-2027 罗马书教学进度的 BSF 讲道法式研经工作台，支持语言自由切换、专业圣经专有名词折算字数检查、教练逐步引导推导与标准大纲导出。
- **Target Audience**: BSF 组长（GL）、讲道者、行政同工及参与罗马书查经的学员。
- **Key Value**: 严谨遵循 BSF 经典规则，告别手动数数和格式混乱，轻松完成合乎规范的命题句、分段和属灵应用大纲。

## 2. User Experience & Visual Design

### Key User Flows
1. **周次选择与模式切换**:
   - 顶部选择当前课次（例如：第 1 课 9/19/26《人类需要福音》罗 1:1-17）。
   - 随时点击顶部语言切换器切换「中文模式」或「English Mode」。
2. **沉浸式经文研读区 (Scripture Panel)**:
   - 显示当前课次的指定经文，支持字体大小缩放与经节点击标记。
   - 语言切换即刻切换为对应经文译本。
3. **BSF 四步教练式向导 (Coach Deck)**:
   - **Step 1: 分段 (Divisions & Headings)**: 划分 2-4 个经文分段，填写分段标题并实施字数校验（中文 $\le 20$ 字，英文 $\le 10$ 词，人名地名算 1 字）。
   - **Step 2: 命题句 (Subject Sentence)**: 全篇主旨句提炼，实时字符分析器展示：实际字符数、识别出的圣经人名地名扣减项、最终 BSF 折算字数，超标时温和标红提示。
   - **Step 3: 核心目的 (Aim)**: 引导句式："Cause audience to know that..." 或 "使会众/读者明白..."。
   - **Step 4: 属灵原则与应用问题 (Principles & Applications)**: 针对每个分段提炼 1 条永恒真理，并设 2 个个人化反思问题。
4. **大纲总览与规范导出 (BSF Standard Export)**:
   - 一览式三列大纲表格：分段与标题 | 属灵原则 | 个人生活应用。
   - 一键复制标准格式文本（支持按当前语言模式导出）。
   - 适配 A4 纸张的打印排版预览。

### Visual Identity & Theme
- **Aesthetic Direction**: 现代学术与典籍研读风格（Archival Sacred Editorial）。
- **Color Palette (60-30-10)**:
  - 60% 羊皮纸温润底色（`bg-[#FBF9F5]`，深色模式为 `bg-[#0F141C]`）。
  - 30% 白净容器卡片与雅致细线（`bg-white`，`border-stone-200 dark:border-stone-800`）。
  - 10% 经典圣经酒红与深邃海军蓝（`#991B1B` / `#1E3A8A`）作为焦点按钮与合规状态标签。
- **Typography**: 衬线标题排版配高质感易读正文字体，支持经文字号随时微调。

### BSF 人名地名合词统计引擎设计 (Name/Place Tokenizer)
- 维护圣经人名地名字库：
  - 中文库包含：`耶稣基督`、`基督耶稣`、`耶稣`、`基督`、`保罗`、`亚伯拉罕`、`摩西`、`大卫`、`亚当`、`以撒`、`雅各`、`法老`、`以赛亚`、`以利亚`、`撒拉`、`利百加`、`非比`、`百基拉`、`亚居拉`、`提摩太`、`罗马`、`耶路撒冷`、`哥林多`、`西班牙`、`锡安`、`马其顿`、`亚该亚`、`坚革哩` 等。
  - 英文库包含：`Jesus Christ`、`Christ Jesus`、`Jesus`、`Christ`、`Paul`、`Abraham`、`Moses`、`David`、`Adam`、`Isaac`、`Jacob`、`Pharaoh`、`Isaiah`、`Elijah`、`Sarah`、`Rebekah`、`Phoebe`、`Priscilla`、`Aquila`、`Timothy`、`Rome`、`Jerusalem`、`Corinth`、`Spain`、`Zion`、`Macedonia`、`Achaia`、`Cenchreae` 等。
- 计数逻辑：
  - **中文**：先识别并提取所有人名地名，每个计 1 个字；其余汉字按单个字计算（排除标点符号）。若最终总字数 $\le 20$，判定合规；并在 UI 提示："实际 X 字符，含 N 个专有名词（每个折算为1字），折算结果：Y 字 / 上限 20 字"。
  - **英文**：按单词分割，双词人名（如 "Jesus Christ"）合并为 1 词计算。总词数 $\le 10$ 为合规。
